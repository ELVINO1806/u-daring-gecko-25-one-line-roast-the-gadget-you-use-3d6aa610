A one-line roast of the gadget that tracks my every move: my fitness watch throws a little celebration each time I stand up, which — given how much of my day happens in a chair — is apparently the peak of my athletic career. Eighty characters, one bruised ego.

## Usage

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`.
